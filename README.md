# ⚡ ForgePlay AI - Neural Game Synthesis Engine

ForgePlay AI is a professional Full-Stack SaaS dashboard that converts game ideas into structured Game Design Documents (GDD) and playable logic using a Neural Synthesis Engine.

### 🚀 Key Features
- **Neural GDD Synthesis:** Generates Story, Mechanics, and Approach from prompts.
- **Live Stimulation Canvas:** Visual runtime preview of game logic.
- **Project Vault:** Persistent storage using Spring Boot & H2 Database.
- **Asset Export:** One-click source code download for developers.

### 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript (Canvas API)
- **Backend:** Java 17, Spring Boot, Spring Data JPA
- **Database:** H2 (File-based persistence)
